# Apiko

[Apiko](https://apiko.app/?utm_source=github-readme&utm_medium=referral&utm_campaign=apiko-app) is an AI API platform and developer gateway for building with modern models through one developer experience.

## What Apiko provides

- Unified access to AI models through a developer-focused API
- Model discovery and catalog browsing
- Developer portal with API documentation and playground workflows
- Usage and billing visibility for teams and applications
- Gateway key management and quota-based access
